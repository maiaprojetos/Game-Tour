# 🏎️ Turbo Nordeste 16-bit

Jogo de corrida pseudo-3D estilo Lotus / Top Gear, com pistas do Nordeste e do Brasil:
Caruaru, Natal, Goiânia, Autódromo Nelson Piquet (RJ), Serra Talhada, BR-101 → João Pessoa e Interlagos.

Feito em um único arquivo HTML (sem dependências), otimizado para iPhone e celulares.

## Como jogar
- ◀ ▶ : dirigir
- FREIO : frear
- TURBO : 3 por corrida
- Teclado: setas / A D / S (freio) / Espaço (turbo)

## Publicar no GitHub Pages
1. Crie um repositório novo no GitHub (ex.: `turbo-nordeste`), público.
2. Envie os arquivos `index.html`, `README.md` e `.nojekyll` (Add file → Upload files).
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, branch **main**, pasta **/(root)** e clique em **Save**.
5. Aguarde 1–2 minutos. O jogo ficará em:
   `https://SEU-USUARIO.github.io/turbo-nordeste/`

No iPhone: abra o link no Safari → Compartilhar → **Adicionar à Tela de Início**.
